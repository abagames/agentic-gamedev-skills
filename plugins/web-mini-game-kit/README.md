# Web Mini-Game Kit

Build crisp-game-lib mini-games, set up licensed game typography, and verify browser runtime health and mechanic conformance.

Version: 0.1.0 · Targets: Codex and Claude Code · Publisher: abagames

## Included skills

- [developing-with-crisp-game-lib](skills/developing-with-crisp-game-lib/SKILL.md)
- [styling-web-game-typography](skills/styling-web-game-typography/SKILL.md)
- [probing-web-game-mechanics](skills/probing-web-game-mechanics/SKILL.md)
- [smoke-testing-web-games](skills/smoke-testing-web-games/SKILL.md)

Each skill directory includes its supporting references, scripts, and assets.

## Requirements and use

Install this directory as a plugin through the target host. Keep the hidden manifest directory and the complete skills tree together.

Resolve skill-local paths against the installed SKILL.md directory, not the game project's working directory.

- Browser probes need Node.js 18+, Playwright, and Chromium available in the target project.
- The crisp-game-lib workflow applies only to projects using crisp-game-lib.
- Fonts must be obtained and licensed for redistribution; font binaries are not bundled.

Tools, engines, model access, and optional companion skills are not installed by this package. Check each skill's prerequisites before use.

Shared skills may also appear in other bundles. Install the bundles you need and select the intended plugin when the host exposes duplicate skills.
