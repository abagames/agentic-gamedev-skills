# Game Concept Workbench

Explore, adversarially test, and curate game concepts before material implementation investment.

Version: 0.1.1 · Targets: Codex and Claude Code · Publisher: abagames

## Included skills

- [exploring-game-design-space](skills/exploring-game-design-space/SKILL.md)
- [stress-testing-game-concepts](skills/stress-testing-game-concepts/SKILL.md)
- [curating-game-concept-portfolio](skills/curating-game-concept-portfolio/SKILL.md)

Each skill directory includes its supporting references, scripts, and assets.

## Requirements and use

Install this directory as a plugin through the target host. Keep the hidden manifest directory and the complete skills tree together.

Resolve skill-local paths against the installed SKILL.md directory, not the game project's working directory.

- Interactive runs may request human review at investment boundaries; unattended runs must complete with review_pending instead of blocking.
- The deterministic portfolio first pass requires Python 3 when structured JSON records are used.

Tools, engines, model access, and optional companion skills are not installed by this package. Check each skill's prerequisites before use.

Shared skills may also appear in other bundles. Install the bundles you need and select the intended plugin when the host exposes duplicate skills.
