# Structural Similarity

Theme is not a primary similarity signal. Compare what the player reads and transforms.

## Anti-reskin questions

Remove nouns from the pitches and ask:

1. What state is read before acting?
2. What does the primary operation transform?
3. What converts action into progress?
4. What makes progress-seeking risky, costly, or committing?
5. What changes in expert play?

If four of five answers remain functionally equivalent, treat the pair as structural neighbors unless a specific causal difference changes strategy.

## Strong duplicate indicators

- same `primary_operation + progress_conversion + risk_coupling` tuple;
- same future-option structure with only different input labels;
- numeric parameter changes only;
- extra content, upgrades, shops, or meta progression around the same core loop;
- camera/theme/art changes without a different decision topology.

Automated clustering must not infer transitivity from these pair signals. Require every pair in a cluster to satisfy the duplicate predicate; A–B and B–C similarity alone does not make distant A and C duplicates. A matching core tuple may extend the ordinary distance threshold for sparse records, but not when known time, control topology, state topology, information, or skill-channel values differ.

## Legitimate reasons to split a cluster

- risk coupling changes the preferred strategy;
- information structure changes what can be inferred before commitment;
- topology changes future option sets rather than only presentation;
- action timing/irreversibility introduces a materially new decision;
- expert behavior uses a different information channel.
